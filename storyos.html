StoryOS · 认知系统

StoryOS
故事认知系统

把复杂的人物与组织决策分析转化为可执行、可比较、可评测的 AI 推理流程：从情境与约束出发，分析选择空间、能动性、决策机制、代价及后续情境变化。

定位个人长期研究项目
核心模型情境 → 选择空间 → 选择 → 新情境
研究资产案例集与知识结构
当前状态原型迭代与评测建设中
01　问题定义

“说得像”不等于“理解了人物”。真正困难的是：为什么这个人在这个情境下只能看到这些选择？

  • 通用大模型可能给出流畅结论，却没有充分说明行动者面对哪些约束、有哪些可行路径，以及为什么作出某项选择。
  • 因果链可能停留在结果解释；事实、推断与心理解释也可能混在一起。
  • 产品目标不是让回答更长，而是把复杂分析转化为可观察、可比较、可评测的推理任务。
02　认知模型

核心链条：情境 → 选择空间 → 能动性 → 选择 → 代价 → 新情境，并持续追问恐惧与欲望。

  • 将情境、选择空间、能动性、选择、代价与新情境连接起来，并持续追问恐惧与欲望。
  • 选择空间的扩大或收缩是观察到的变化现象；核心在于制度、资源、权力与规则如何让某些选择成为可能或不可能。
  • 把组织结构、制度规则、资源与时代因素作为系统变量，避免只用性格标签解释行动。
03　知识系统

把人物、事件与系统变量分开建模，再用跨案例样本检查分析是否遗漏约束、跳过因果或过度心理化。

  • 以人物、事件与组织系统为不同分析对象，持续检查模型是否遗漏约束、跳过因果或过度心理化。
  • 已通过 Python、Streamlit 与 DeepSeek API 搭建原型，并设置 Baseline 与 StoryOS 两条输出路径进行对照。
  • 将案例分析转化为可复核的评测资产，而不把单次回答的说服力等同于稳定的模型能力。
04　产品价值

StoryOS 是一次把复杂认知任务变成可评测 AI 产品的实验。

  • 建立九维人工评测框架：情境准确性、选择空间、能动性、选择机制、代价分析、因果链、证据可靠性、选择空间变化真实性、分析边界遵守度。
  • 五个已恢复完整九维评分的案例（改稻为桑、明朝制度、诺基亚、令狐冲、孙权）综合人工评分平均为 Baseline 3.18/5、StoryOS 3.82/5，平均分差 +0.63/5。
  • 逐维平均分差较明显的维度包括选择空间（+1.28）、能动性（+1.26）、因果链（+1.06）与选择空间变化真实性（+1.72）；情境准确性（-0.36）与分析边界遵守度（-0.20）则提示风险。
  • 以上为现有样例的描述性人工评分，尚未完成盲评、多评估者一致性检验及独立事实核验；不能据此宣称已证明通用模型能力提升。
05　下一步

下一阶段重点不是继续堆叠案例，而是提高评测可信度，并把产品能力放进真实任务中验证。

迭代优先级

统一输入与评分口径；区分事实、推断与解释；补充关键事实核验、盲评与多评估者一致性检验；增加信息缺失、前提错误和多种替代解释等反向测试。Engine → 认知智能体 → 个人认知系统是长期演进方向，不代表这些阶段已全部实现。
