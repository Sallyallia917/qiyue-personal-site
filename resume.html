代表项目

AI 医患沟通自动化 ↗

真实业务项目

问题：在高频、非结构化的医疗沟通中兼顾回复准确性、场景适配与风险边界。

产品决策：把场景自动化评估、样本测试、Prompt / 规则迭代与人工接管边界放在同一条质量闭环中，而不是只优化单轮回复。

证据：项目阶段记录中的标签准确率为 85% 以上、回复 / 话术准确率约 95%；具体统计口径与个人负责范围以可核实的项目记录为准。

StoryOS 故事认知系统 ↗

独立 AI 产品项目

问题：将复杂人物与组织决策分析转化为可执行、可比较、可评测的 AI 推理任务，避免输出停留在性格标签或结果复述。

设计与实现：建立“情境—选择空间—能动性—选择—代价—新情境”推理链，基于 Python、Streamlit 与 DeepSeek API 搭建原型，并设置 Baseline 与 StoryOS 输出对照。

评测：设计九维人工评测框架；五个完整九维评分案例的综合平均分为 Baseline 3.18/5、StoryOS 3.82/5，平均分差 +0.63/5。选择空间、能动性、因果链与选择空间变化真实性等维度呈现积极信号。

边界与迭代：当前评分尚未经过盲评、多评估者一致性检验及独立事实核验；后续优先完善证据分层、事实核验与分析边界控制。

咖啡增长行动引擎 ↗

独立应用原型

问题：探索如何把消费者研究转化为会员触达、商品推荐与优惠决策。

设计：把决策层拆为可测试的确定性规则：会员分群、商品候选筛选 / 排序、优惠预算与折后毛利校验；大模型仅规划用于后续营销表达，不直接决定优惠风险。

状态：完整数据加载、服务编排、LLM 营销文案与端到端运行仍待开发；当前不宣称已提升复购或转化。
