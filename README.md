## 本地预览
直接打开 `index.html` 即可查看。若浏览器对本地文件跳转有限制，可在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 免费部署到 GitHub Pages
1. 解压本 ZIP，将 `qiyue-personal-site-v0.9/` 文件夹里的**所有文件**上传到 GitHub 仓库根目录（不要多套一层文件夹）。
2. GitHub 仓库进入 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/(root)`，保存。
5. 等待 GitHub Pages 构建完成，在 Settings → Pages 查看公开网址。
6. 后续修改 HTML/CSS 并推送到 `main`，即可继续迭代发布。

## 发布前核对
- 确认工作经历数据、准确率与项目描述均可公开且有依据。
- 当前没有填写个人邮箱、微信二维码或公众号文章直链；公众号以微信搜索方式呈现。
- 个人咨询描述属于成长与行动支持，不宣称心理治疗或未经验证的专业资质。
- 个人项目的线上 Demo、代码仓库、评测样例暂未全部添加；有真实地址后再补，不虚构链接。
- 不要在静态网页或 GitHub 仓库中放置 API Key、密码或客户隐私数据。
