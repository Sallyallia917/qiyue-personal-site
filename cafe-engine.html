AI 应用项目

咖啡服务
行动引擎

把咖啡消费中的用户信息转化为下一步行动，连接路由、情绪、记忆、满意度、工单与优惠机制。

场景精品咖啡服务
目标从信息到行动
技术RAG / LangChain / FastAPI
交付Streamlit → Gradio / Render
01　场景与问题

真正的问题不是推荐一杯咖啡，而是这次对话之后系统下一步能做什么？

  • 识别意图与情绪。
  • 利用历史信息形成连续服务。
  • 满意度下降时触发工单或补救。
  • 合适时机使用优惠或其他行动。
02　系统设计

把服务拆成 任务路由、情绪识别、记忆、满意度、服务工单、优惠机制 等可组合能力。

  • 任务路由：判断任务。
  • 记忆：保留后续服务有价值的信息。
  • 满意度：判断服务结果。
  • 服务工单 / 优惠机制：把判断转化为业务动作。
03　技术路径

从 Streamlit / LangChain / RAG / DeepSeek 验证，再演进到 Gradio + Render + FastAPI。

  • 先验证产品逻辑，再增加工程化。
  • 通过 API 化让能力脱离单一 演示。
  • 技术选型围绕验证速度与可迁移性。
04　产品判断

沉淀一个可迁移的 行动引擎：信息理解 → 状态判断 → 行动决策 → 结果反馈。

  • 客服、酒旅、餐饮、营销服务都可以复用这一抽象。
  • AI 商业价值最终要落到下一步行动，而不仅是生成内容。
